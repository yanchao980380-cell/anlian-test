# 人物志

沿用项目的密码入口、单题选择、进度条与分段报告结构。纯静态页面，从合集首页进入 `history/`，无需安装项目依赖。访问密码为 `9800`。

## 内容

- 18题，6个偏好维度，8位历史人物原创风格原型。
- 明确主结果、作答依据、六维偏好、优势、挑战、生活场景、个性化补充、7天清单、人物背景资料。
- 墨绿与古金配色，纸色卡片、山水图形和印章元素。
- 结果页采用人物档案卡、风格标签、六维雷达图、章节跳转和行动进度条；独立的 `report.css` 负责结果页样式。
- 支持当前标签页内的作答恢复、回看修改、清单勾选、复制和下载完整文字报告。

`data.js` 保存题目、原型、报告及纯匹配函数；`app.js` 管理交互；`style.css` 管理视觉。

人物插画入口为 `portraits.js`，8张用户提供的原图保存在 `assets/portraits/`，按人物 ID 与结果页一一对应。图片保留原始内容，以完整方图展示。

## 匹配规则

每个维度3题，含反向题。0–4分换算后取均值，与8个人物向量进行等权平方距离比较。最小距离为主结果，同分按人物配置顺序固定展示并提示；全选同一选项提示区分度有限。结果不使用虚构准确率或相似概率。

原型是原创文化联想，不是对历史人物的心理测量，也不是专业人格鉴定。背景资料与原创解读分开呈现。

## 验证

在仓库根目录运行 `node --test tests/history.test.cjs`。浏览器测试为 `tests/history.browser.cjs`，需要本地预览服务位于 `http://127.0.0.1:8080/`，以及 Playwright 和 Chrome；可用 `NODE_PATH` 指向已有 Playwright 的包目录。截图默认写入系统临时目录，可用 `HISTORY_TEST_OUTPUT` 指定输出目录。

访问密码与原项目一样只在前端校验，不构成服务端授权或付费内容保护。作答与清单通过 sessionStorage 保存在当前浏览器标签页，关闭后可能清除；下载文字报告可长期保存。此功能不向服务器提交答卷。
